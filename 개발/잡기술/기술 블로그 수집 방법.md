# 기술 블로그 수집 방법

## 결론

**RSS로 수집 → Readability 계열로 본문 추출 → 마크다운으로 Obsidian 볼트에 저장**, 이 3단 파이프라인이 정답이다. 크롤러를 직접 짜는 것보다 피드를 긁는 쪽이 압도적으로 싸고 안 깨진다.

구축 난이도에 따라 3가지 시나리오가 있다. 처음이면 **시나리오 A(30분)** 로 시작해서, 손으로 클리핑하는 게 귀찮아지는 시점에 **시나리오 B**로 넘어가면 된다.

| 시나리오 | 구성 | 소요 시간 | 자동화 수준 |
|---|---|---|---|
| A. 최소 | Obsidian Web Clipper 확장만 | 30분 | 수동 (읽다가 버튼 클릭) |
| B. 권장 | Miniflux + Python 스크립트 | 반나절 | 자동 (별표한 글만 자동 저장) |
| C. 완전 | B + LLM 요약/태깅 + 스케줄러 | 1~2일 | 완전 자동 (요약까지) |

---

## 전체 구조

```
[기술 블로그들]
      │ RSS/Atom 피드
      ▼
[1. 수집기]  Miniflux / FreshRSS / Inoreader
      │ API로 "별표한 항목" 조회
      ▼
[2. 본문 추출]  trafilatura / Readability.js / Jina Reader
      │ HTML → 깨끗한 마크다운
      ▼
[3. 후처리]  LLM 요약 + 태그 생성 (선택)
      │
      ▼
[4. 저장]  C:\Users\com\Obsidian\Study_Obsidian\스크랩\*.md
      │ 프론트매터 + 본문
      ▼
[5. 활용]  Dataview로 주간 리뷰 대시보드
```

## 시나리오 A: 최소 구성 (수동, 30분)

가장 빠르게 효과를 보는 방법이다. 자동화 없이 "읽다가 좋으면 버튼 클릭"으로 끝난다.

### 구축 순서

1. Chrome/Edge에 **Obsidian Web Clipper** 공식 확장 설치
2. 확장 설정에서 볼트를 `Study_Obsidian`으로, 저장 폴더를 `스크랩/`으로 지정
3. 템플릿을 아래처럼 등록

### 템플릿 설정

Web Clipper의 강점은 **URL 패턴별로 다른 템플릿**을 적용할 수 있다는 점이다. 설정 → Templates에서 새 템플릿을 만들고 트리거 조건을 URL 정규식으로 준다.

기본 템플릿 (Note content):

```markdown
---
title: "{{title}}"
source: "{{url}}"
author: "{{author}}"
published: {{published}}
clipped: {{date}}
tags:
  - 스크랩
status: 미독
---

> [!info] 원문
> [{{title}}]({{url}})

## 메모


## 본문

{{content}}
```

URL 트리거 예시:

| 트리거 | 자동 부여 태그 |
|---|---|
| `https://techblog.woowahan.com` | `스크랩/아키텍처` |
| `https://toss.tech` | `스크랩/프론트` |
| `https://blog.cloudflare.com` | `스크랩/보안` |
| `https://news.hada.io` | `스크랩/소식` |

이렇게 해두면 클리핑 시점에 분류가 끝난다. 나중에 정리하겠다고 미루면 절대 안 한다.

### 한계

- 브라우저를 열고 직접 눌러야 한다
- 놓친 글은 영영 안 들어온다
- 그래서 결국 시나리오 B가 필요해진다

## 시나리오 B: 자동 수집 파이프라인 (권장)

RSS 리더에서 **별표(starred)만 찍어두면** 스크립트가 알아서 본문을 뽑아 볼트에 떨군다. 읽는 행위와 저장하는 행위가 분리되는 게 핵심이다.

### 2-1. Miniflux 설치 (Docker)

Go 단일 바이너리 + PostgreSQL. 메모리 50MB 수준으로 돈다. FreshRSS보다 가볍고 API가 깔끔해서 자동화 붙이기 좋다.

`docker-compose.yml`:

```yaml
services:
  miniflux:
    image: miniflux/miniflux:latest
    container_name: miniflux
    ports:
      - "8080:8080"
    depends_on:
      db:
        condition: service_healthy
    environment:
      - DATABASE_URL=postgres://miniflux:secret@db/miniflux?sslmode=disable
      - RUN_MIGRATIONS=1
      - CREATE_ADMIN=1
      - ADMIN_USERNAME=admin
      - ADMIN_PASSWORD=변경할것
      - POLLING_FREQUENCY=60          # 60분마다 피드 확인
      - CLEANUP_ARCHIVE_UNREAD_DAYS=90
    restart: unless-stopped

  db:
    image: postgres:17-alpine
    container_name: miniflux-db
    environment:
      - POSTGRES_USER=miniflux
      - POSTGRES_PASSWORD=secret
      - POSTGRES_DB=miniflux
    volumes:
      - miniflux-db:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD", "pg_isready", "-U", "miniflux"]
      interval: 10s
      start_period: 30s
    restart: unless-stopped

volumes:
  miniflux-db:
```

```bash
docker compose up -d
# http://localhost:8080 접속 → admin / 설정한 비번
```

접속 후 **Settings → API Keys**에서 API 키를 발급받는다. 스크립트가 이걸 쓴다.

### 2-3. 본문 추출 + 저장 스크립트

Miniflux API로 별표한 항목을 가져와, 본문을 추출하고, 프론트매터를 붙여 볼트에 저장한다.

```bash
pip install trafilatura requests python-slugify
```

`scrap.py`:

```python
#!/usr/bin/env python3
"""
Miniflux에서 별표(starred)한 글을 가져와 Obsidian 볼트에 마크다운으로 저장한다.
- 이미 저장한 글은 건너뛴다 (entry id 기준)
- 저장에 성공하면 Miniflux에서 별표를 해제한다 (중복 방지)
"""
import os
import re
import json
import pathlib
import datetime as dt

import requests
import trafilatura

# ── 설정 ──────────────────────────────────────────────
MINIFLUX_URL = "http://localhost:8080"
API_KEY      = os.environ["MINIFLUX_API_KEY"]      # 환경변수로 관리
VAULT        = pathlib.Path(r"C:\Users\com\Obsidian\Study_Obsidian\스크랩")
STATE_FILE   = VAULT / ".saved_ids.json"
UNSTAR_AFTER = True    # 저장 후 별표 해제 여부

HEADERS = {"X-Auth-Token": API_KEY}

# 카테고리명 → Obsidian 태그 매핑
TAG_MAP = {
    "국내": "스크랩/국내",
    "해외": "스크랩/해외",
    "비즈니스": "스크랩/비즈니스",
    "소식": "스크랩/소식",
}


def safe_filename(title: str) -> str:
    """윈도우 파일명으로 못 쓰는 문자를 제거한다."""
    name = re.sub(r'[\\/:*?"<>|]', "", title).strip()
    return name[:80] or "untitled"


def load_state() -> set:
    if STATE_FILE.exists():
        return set(json.loads(STATE_FILE.read_text(encoding="utf-8")))
    return set()


def save_state(ids: set) -> None:
    STATE_FILE.write_text(
        json.dumps(sorted(ids), ensure_ascii=False), encoding="utf-8"
    )


def fetch_starred() -> list:
    """별표한 항목을 최신순으로 가져온다."""
    r = requests.get(
        f"{MINIFLUX_URL}/v1/entries",
        headers=HEADERS,
        params={"starred": "true", "limit": 100, "direction": "desc"},
        timeout=30,
    )
    r.raise_for_status()
    return r.json().get("entries", [])


def extract_body(url: str, fallback_html: str) -> str:
    """원문 URL에서 본문을 추출한다. 실패하면 피드 내용으로 대체한다."""
    downloaded = trafilatura.fetch_url(url)
    if downloaded:
        md = trafilatura.extract(
            downloaded,
            output_format="markdown",
            include_links=True,
            include_images=True,
            include_tables=True,
            favor_precision=True,
        )
        if md and len(md) > 200:
            return md
    # 폴백: 피드에 실린 HTML을 그대로 변환
    md = trafilatura.extract(fallback_html, output_format="markdown")
    return md or "(본문 추출 실패 — 원문 링크를 확인하세요)"


def to_note(entry: dict) -> str:
    title    = entry["title"]
    url      = entry["url"]
    author   = entry.get("author") or ""
    site     = entry["feed"]["title"]
    category = entry["feed"].get("category", {}).get("title", "")
    published = entry["published_at"][:10]
    today     = dt.date.today().isoformat()

    tag = TAG_MAP.get(category, "스크랩/기타")
    body = extract_body(url, entry.get("content", ""))

    return f"""---
title: "{title.replace('"', "'")}"
source: "{url}"
site: "{site}"
author: "{author}"
published: {published}
clipped: {today}
tags:
  - {tag}
status: 미독
---

> [!info] 원문
> [{title}]({url}) — {site}

## 메모


## 본문

{body}
"""


def unstar(entry_id: int) -> None:
    requests.put(
        f"{MINIFLUX_URL}/v1/entries/{entry_id}/bookmark",
        headers=HEADERS,
        timeout=15,
    )


def main() -> None:
    VAULT.mkdir(parents=True, exist_ok=True)
    saved = load_state()
    entries = fetch_starred()

    new_count = 0
    for e in entries:
        eid = str(e["id"])
        if eid in saved:
            continue

        published = e["published_at"][:10]
        fname = f"{published} {safe_filename(e['title'])}.md"
        path = VAULT / fname

        try:
            path.write_text(to_note(e), encoding="utf-8")
        except Exception as err:
            print(f"[실패] {e['title']}: {err}")
            continue

        saved.add(eid)
        new_count += 1
        print(f"[저장] {fname}")

        if UNSTAR_AFTER:
            unstar(e["id"])

    save_state(saved)
    print(f"\n완료: 신규 {new_count}건 / 누적 {len(saved)}건")


if __name__ == "__main__":
    main()
```

실행:

```powershell
$env:MINIFLUX_API_KEY = "발급받은키"
python scrap.py
```

## 시나리오 C: LLM 요약/태깅 추가

스크랩은 쌓기는 쉬운데 **안 읽는 게 문제**다. 저장 시점에 요약을 붙여두면 나중에 검색했을 때 실제로 쓰인다.

`scrap.py`의 `to_note()` 앞에 아래 함수를 끼워 넣는다.

```python
import anthropic

client = anthropic.Anthropic()   # ANTHROPIC_API_KEY 환경변수 사용

SUMMARY_PROMPT = """다음 기술 블로그 글을 읽고 아래 JSON 형식으로만 답하라.

{{
  "summary": ["핵심 요약 3줄, 각 줄 40자 내외"],
  "tags": ["소문자 영문 또는 한글 키워드 3~5개"],
  "relevance": "이 글이 다루는 기술 영역을 한 단어로"
}}

제목: {title}

본문:
{body}
"""


def summarize(title: str, body: str) -> dict:
    """본문을 요약하고 태그를 뽑는다. 실패하면 빈 값을 반환한다."""
    try:
        msg = client.messages.create(
            model="claude-sonnet-4-5",
            max_tokens=1000,
            messages=[{
                "role": "user",
                "content": SUMMARY_PROMPT.format(
                    title=title, body=body[:12000]   # 토큰 절약
                ),
            }],
        )
        text = msg.content[0].text.strip()
        # 코드펜스가 붙어 오는 경우 제거
        text = re.sub(r"^```(?:json)?|```$", "", text, flags=re.M).strip()
        return json.loads(text)
    except Exception as err:
        print(f"  (요약 실패: {err})")
        return {"summary": [], "tags": [], "relevance": ""}
```

`to_note()`에서 활용:

```python
    body = extract_body(url, entry.get("content", ""))
    ai = summarize(title, body)

    summary_block = "\n".join(f"> - {s}" for s in ai["summary"]) or "> (요약 없음)"
    extra_tags = "\n".join(f"  - {t}" for t in ai["tags"])

    return f"""---
title: "{title.replace('"', "'")}"
source: "{url}"
site: "{site}"
published: {published}
clipped: {today}
relevance: "{ai['relevance']}"
tags:
  - {tag}
{extra_tags}
status: 미독
---

> [!abstract] 3줄 요약
{summary_block}

> [!info] 원문
> [{title}]({url}) — {site}

## 메모


## 본문

{body}
"""
```

> [!warning] 비용
> 글 하나당 대략 1~2원 수준이다. 하루 10건이면 월 500원 안팎. 본문을 `[:12000]`으로 자르는 게 비용 방어의 핵심이다.

## Obsidian 쪽 활용 설정

### Dataview 대시보드

`스크랩/_대시보드.md` 를 만들고 아래를 넣는다. 수집만 하고 안 읽는 사태를 막는 장치다.

````markdown
## 아직 안 읽은 글

```dataview
TABLE site AS "출처", published AS "발행", relevance AS "분야"
FROM "스크랩"
WHERE status = "미독"
SORT clipped DESC
LIMIT 20
```

## 이번 주 수집

```dataview
TABLE WITHOUT ID file.link AS "글", site AS "출처"
FROM "스크랩"
WHERE clipped >= date(today) - dur(7 days)
SORT clipped DESC
```

## 분야별 집계

```dataview
TABLE length(rows) AS "건수"
FROM "스크랩"
GROUP BY relevance
SORT length(rows) DESC
```
````

### 운용 원칙

- `status` 는 `미독 → 정독 → 보관` 3단계로만 둔다. 더 세분화하면 관리를 안 하게 된다
- 주 1회 대시보드를 열어 미독 목록을 훑고, 안 읽을 것 같으면 과감히 삭제한다
- 「메모」 섹션에 한 줄이라도 적은 글만 `보관`으로 올린다. 이게 나중에 제안서·보고서에서 인용할 자산이 된다

## 본문 추출 기술 비교

| 도구 | 언어 | 정확도 | JS 렌더링 | 비고 |
|---|---|---|---|---|
| **trafilatura** | Python | 최상 | ✕ | 메타데이터(저자·발행일)까지 추출, 마크다운 직접 출력 |
| **Readability.js** | JS | 상 | ✕ | 파이어폭스 리더뷰 엔진, jsdom 필요 |
| **Jina Reader** | API | 상 | ○ | `r.jina.ai/{URL}` 로 즉시 사용, 설치 불필요 |
| **Firecrawl** | API | 최상 | ○ | 상용, 크롤링+추출 통합, 규모 커지면 고려 |
| **Playwright + Readability** | 양쪽 | 최상 | ○ | 가장 무겁지만 SPA도 확실히 처리 |

### 프로토타이핑 단축키

설치 없이 바로 시험하려면 Jina Reader가 가장 빠르다.

```python
import requests

def quick_extract(url: str) -> str:
    r = requests.get(f"https://r.jina.ai/{url}", timeout=30)
    r.raise_for_status()
    return r.text    # 이미 마크다운
```

### SPA 대응

trafilatura가 빈 껍데기를 가져오면 JS 렌더링 페이지다. Playwright로 렌더링 후 넘긴다.

```python
from playwright.sync_api import sync_playwright
import trafilatura

def extract_spa(url: str) -> str:
    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page()
        page.goto(url, wait_until="networkidle", timeout=30000)
        html = page.content()
        browser.close()
    return trafilatura.extract(html, output_format="markdown") or ""
```

## 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 본문이 비어서 저장됨 | JS 렌더링 페이지 | Playwright 경유로 전환 |
| 한글이 깨짐 | 인코딩 미지정 | `write_text(..., encoding="utf-8")` 확인 |
| 파일명 오류 | 윈도우 금지 문자 | `safe_filename()` 적용 |
| 403 / 429 응답 | 요청 과다 또는 UA 차단 | 요청 간 1초 이상 대기, User-Agent 지정 |
| 같은 글이 반복 저장 | 상태 파일 유실 | `.saved_ids.json` 경로 확인, 별표 해제 로직 확인 |
| Miniflux 피드 갱신 안 됨 | 폴링 주기 | `POLLING_FREQUENCY` 조정, 수동 Refresh |

---

## 주의사항

**robots.txt와 이용약관은 확인한다.** RSS는 배포를 목적으로 공개된 채널이라 안전하지만, 본문 전체를 긁어 **재배포**하는 것은 별개 문제다.

- 개인 아카이브 용도로 로컬 볼트에 두는 것은 일반적으로 문제되지 않는다
- 보고서·제안서에 인용할 때는 **원문 링크와 출처를 반드시 남긴다**
- 요청 간격은 최소 1초 이상 두고, User-Agent에 연락처를 남기는 것이 매너다
- 유료 콘텐츠(Stratechery 등)는 피드에 요약만 오는 경우가 많다. 우회 추출을 시도하지 않는다

```python
HEADERS_FOR_FETCH = {
    "User-Agent": "PersonalArchiveBot/1.0 (+개인 아카이브 용도)"
}
```
