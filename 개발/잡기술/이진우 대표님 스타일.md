### A 로직을 짜는 순서

A-1 선조회->맵 구성->본 루프 3단 구조
```python
# 1) 본 루프에서 필요한 조회용 자료구조를 먼저 전부 만든다
public_rts, explicit_map, main_map = set(), {}, {}
for rt in self._cache['route_tables']:
    ...
    public_rts.add(rt_id)
    explicit_map[subnet_id] = rt_id
    main_map[vpc_id] = rt_id

# 2) 본 루프는 O(1) 조회만 한다
for raw in self._cache[Category.SUBNET]:
    target_rt = explicit_map.get(resource_id) or main_map.get(raw.get('VpcId'))
    is_public = target_rt in public_rts
```
why:중첩루트(O(n*m))을 피하고 변환만 하는 단순한 모양 유지, 조회로직과 변환 로직이 섞이지 않음.
practice: 두 리스트를 대조하는 코드를 쓸 때마다 안쪽 루프를 dict/set으로 바꿔보기
`by_id = {str(n['id']): n for n in nodes}` 를 손이 먼저 치게 만들기.

A-2 관계는 집합 연산으로 푼다
```python
secgroups = {n.data.id for n in element.nodes if n.data.category == Category.SECGROUP}
attached: Set[UUID] = set()
...
attached |= _referenced_secgroups(element)          # 합집합
compliant = [i for i, sgs in attached.items()
             if i not in violating and not (sgs & violating)]   # 교집합으로 "하나라도 겹치나"
return targets - not_applied                        # 차집합으로 "적용된 것"
```
why: A에 속하면서 B에 없는 것, 하나라도 겹치는가를 in/&/-/|로 쓰면 의도가 한 줄에 드러나고 중복 처리도 공짜임.
연습: 미사용X찾기, Y와 연결되지 않은 Z찾기 류 문제를 전부 집합 식으로 먼저 종이에 쓴 뒤 코드로 옮기기.

A-4 ensure 패턴 - 멱등하게 만들고 참조를 돌려준다.
```python
key = f'secgroup_{data.id.hex}'
ref = f'${{aws_security_group.{key}.{attr}}}'
res: dict = tf.setdefault(data.binding.resource_type, {})
obj: dict = res.setdefault('aws_security_group', {})
if key in obj:
    return ref            # 이미 만들었으면 참조만 돌려준다
obj[key] = {}             # 먼저 자리를 잡고 (재귀 호출 시 중복 방지)
...
if not (vpc_ref := self._process_vpc(tf, vpc)):   # 의존 리소스는 재귀로 ensure
    del obj[key]; return None
```
why: 리소스 간 의존(서브넷->VPC)을 호출 순서에 기대지 않고, 필요한 쪽이 상위를 호출해 보장받습니다. 몇 번 불려도 결과가 같습니다. setdefault체인은 중첩 dict를 만드는 사용구입니ㅏㄷ.
연습: 트리/그래프 형태의 출려물(Json,HCL,DOM)을 만들 떄 이미 있으면 그걸 반환 없으면 만들고 반환 함수를 먼저 쓰고 그 위에 조립하기.
