엔터티의 세부 항복 기본/셜계/파생

### 정의
속성이란 엔터티가 가지는 세부 정보 항목 곧 컬럼이며 엔터티를 설명하는 가장 작은 단위


###  개념정리

| Mem | ber | 테이블  |
| :-: | :-: | :--: |
| ID  | 이름  | 전화번호 |
|  1  |  1  |  1   |
이렇게 있을 때 각 행은 인스턴스, 각 칸은 속성 값, 각 컬럼은 속성이다.

### 속성의 3가지 분류기준
- 특성
	- 기본 속성
	- 설계 속성
	- 파생 속성
- 분해 가능 여부
	- 단순 속성
	- 복합 속성
- 속성 값의 개수
	- 단일값의 속성
	- 다중값의 속성
