서브쿼리는 쿼리 안에 들어 있는 또 다른 쿼리다.

#### 서브쿼리의 위치
SELECT 칼럼들 FROM (서브쿼리)

SELECT 서브쿼리(스칼라), FROM 서브쿼리(인라인 뷰), WHERE 서브쿼리(대표적)

#### 서브쿼리의 분류
- 결과 행수에 따른 분류
	- 단일행 서브쿼리
	- 다중행 서브쿼리
	- 다중컬럼 서브쿼리
- 위치에 따른 분류
	- Select절 스칼라 서브쿼리
	- FROM절 인라인 뷰
	- WHERE절 중첩 서브쿼리
- 메인 쿼리와의 관계
	- 비연관 서브쿼리 - 메인쿼리 컬럼 사용 안 함/한 번만 실행
	- 연관 서브쿼리 - 메인쿼리 컬럼 참조 / 메인의 각 행마다 반복 실행

#### 서브쿼리 vs 조인 vs 집합 연산자
- SUB 메인쿼리에 값 하나(또는 집합)을 공급. 보조 쿼리
- 조인 컬럼을 옆으로 붙임. 두 테이블의 행 결합
- 집합 연산자 행을 위아래로 이어붙임

단일행 서브쿼리 - 서브쿼리 결과가 1행 1값
다중행 서브쿼리 - IN/ANY/ALL
EXISTS 서브쿼리
- 결과가 존재하기만 하면 TRUE - 1건이라도 있으면 통과
- IN보다 효율적일 수 있음 - 존재 확인만 하면 됨
