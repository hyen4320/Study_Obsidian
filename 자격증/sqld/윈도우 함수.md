RANK / ROW_NUMBER / LAG / LEAD

윈도우 함수는 행을 합치지 않으면서 행마다 그룹별 통계나 순위를 옆에 붙여주는 함수다.

일반 집계(GROUP BY) VS 윈도우 함수(OVER)
행이 그룹별로 합쳐짐      행은 그대로 유지 옆에 분석값
결과 1행                       결과 N행 (원본과 같음)
AVG=4000                     NAME SAL RANK AVG 모두 보임

#### 기본 문법 
함수명(컬럼) OVER(
	 PARTITION BY 그룹 기준 -- 어떻게 묶을지
	 ORDER BY 정렬 기준  ------ 어떻게 정렬할지
	 ROWS BETWEEN ... AND ...   어디부터 어디까지(윈도우)
)

#### 윈도우 함수의 분류
- RANK 동점 같은 등수, 다음 건너뀜(1,1,3)
- DENSE_RANK 동점 같은 등수 다음 연속(1,1,2)
- ROW_NUMBER 동점 무시, 모두 다른 등수(1,2,3)
- NTILE N등분 그룹 번호 부여
- LAG(col,n) n행전 값, 기본값 1
- LEAD(col,n)
- FIRST_VALUE or LAST_VALUE 윈도우 첫 값, 윈도우 마지막 값
- SUM/AVG/COUNT/MAX/MIN

비율 함수
- CUME_DIST() 누적 비율
- PERCENT_RANK() 백분위 순위
- NTILE(N) N등분 그룹
- RATIO_TO_REPORT(col) 전체 합 대비 비율-Oracle한정
