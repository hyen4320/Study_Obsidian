DDL/DML/DCL/TCL 분류

### 데이터베이스의 구조
DBMS->Database->Table

### SQL 명령어 분류
DDL=정의어(표_설계도 만들기/바꾸기)
- CREATE, ALTER, DROP, TRUNCATE, RENAME
DML=조작어(표 안의 데이터 조작)
- SELECT INSERT UPDATE DELETE MERGE
DCL=제어어(권한 부여/회수)
- GRANT REVOKE
TCL=트랜잭션(트랜잭션 묶음 처리)
- COMMIT ROLLBACK SAVEPOINT
(TRUNCATE는 DDL, DELETE는 DML이다)헷갈리기 쉬움

#### 주요 데이터 타입
CHAR(n) - 고정 길이 문자열
VARCHAR2(n) - 가변 길이 문자열
Number(p,s) - 숫자
DATE - 날짜+시간
TIMESTAMP - 정밀시간

### ACID
트랜잭션에 핵심 약속으로 
전부 성공 or 전부 실패
규칙 유지
동시 처리 시 격리
커밋 후 영구 저장

DDL->DML->TCL->DCL 흐름으로 진행됨.

#### 파일시스템 vs RDB

빠른검색, 동시처리, 무결성 제약이 보장됨
RDB의 5대 장점
데이터 독립성, 중복 최소화, 무결성, 보안, 동시성

데이터 독립성 - DB 변경이 응용 프로그램에 영향을 덜 줌
데이터 중복 최소화 - 정규화로 일관성 유지
무결성 - 제약조건으로 잘못된 데이터 차단
보안 - DCL로 권한 관리
동시성 - 트랜잭션 격리로 충돌 방지
