단일행/문자/숫자/날짜/변환/NULL

#### 단일행
- 문자
	- upper-대문자
	- lower-소문자
	- substr-추출
	- instr-위치찾기
	- length-길이
	- LPAD/RPAD-패딩
	- LTRIM/RTRIM/TRIM-공백제거
	- REPLACE-교체
	- CONCAT-연결
- 숫자
	- ABS-절댓값
	- ROUND-반올림
	- TRUNC-버림
	- MOD-나머지
	- POWER-거듭제곱
	- CEIL-올림
	- FLOOR-내림
	- SIGN-부호
- 날짜 함수
	- SYSDATE - 현재 날짜 + 시간
- 변환 함수
	- TO_CHAR(d,'YYYY-MM-DD')
	- TO_CHAR(n,'999,999')
	- TO_NUMBER('1234')
	- TO_DATE('20260426,'YYYYMMDD')
- NULL 관련 함수
	- NVL(A,B) - A가 NULL이면 B로 대체
	- NVL2(A,B,C) - A가 NULL 아니면 B NULL이면 C
	- NULLIF(A,B) - A=B면 NULL 아니면 A
	- COALESCE(A,B,....) NULL이 아닌 첫 값 반환

#### 다중행(집계)함수
COUNT( * ) 모든 행, 수 NULL포함
COUNT(col) 컬럼 NULL 제외 NULL 제외
SUM(col) 합 NULL무시
AVG(col) 평균 NULL무시
MAX(col) 최대 NULL무시
MIN(col) 최소 NULL무시
