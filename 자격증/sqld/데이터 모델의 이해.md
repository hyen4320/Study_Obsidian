데이터 모델은 현실 세계의 복잡한 정보를 컴퓨터에 저장하기 위해 그린 설계 도면.
개-논-물
### 데이터 모델링의 3단계
개-논-물
개념적: ERD생성
논리적: 정규화, 속성 pk fk 채움
물리적: 실제 테이블 만들기, 자료형 인덱스 제약조건 명시

### 데이터 모델링 3가지 관점
데이터 관점 - 무엇을(What) 저장하지
프로세스 관점 - 어떻게(How) 처리하지
상관관계 관점 - 언제(When) 어떤 데이터가 변하지

### 좋은 데이터 모델의 특징
완전성, 중복 배제, 업무규칙, 데이터 재사용, 의사소통, 통합성

### 3층 스키마
같은 데이터베이스를 3가지 관점에서 본 모습
외부스키마-각 사용자/앱이 보는 화면
개념스키마-조직 전체가 공유하는 ERD
내부스키마-디스크 위 실제 저장 구조

(내부스키마->개념스키마) 물리적 독립성이 적용됨
(개념스키마->외부스키마) 논리적 독립성이 적용됨

3층이 분리된 이유:데이터 독립성
