## 발전 단계

| 시기 | 단계 | 핵심 | 판단 단위 |
| --- | --- | --- | --- |
| ~2000년대 | 경계 보안 | 방화벽 · VPN · DMZ, 내부는 신뢰 | 네트워크 입구 1회 |
| 1994–2009 | 개념 태동 | Marsh 1994 용어, Jericho Forum 탈경계화 | — |
| 2010 | 네트워크 중심 | Kindervag(Forrester), 보호 표면 · 마이크로세그멘테이션 | 네트워크 구간 |
| 2013–2019 | ID · 접근 중심 | CSA SDP, Google BeyondCorp, ZTX, ZTNA · SASE | 사용자 + 기기 + 요청 |
| 2020–2023 | 표준 · 정책화 | NIST 800-207, EO 14028, M-22-09, CISA ZTMM, DoD 전략 | PE · PA · PEP |
| 2024–2025 | 구현 · 성숙도 | NIST 1800-35, KISA 2.0, N2SF | 조합 · 측정 |
| 2026– | AI 에이전트 확장 | 에이전트 ID, NHI, 위임 체인, 의도 검증 | 에이전트 행위 |

### 단계별 아키텍처 변화

- **SDP** — 제어 평면(컨트롤러)과 데이터 평면(게이트웨이) 분리. 인증 전 서비스 은닉(SPA)
- **BeyondCorp** — VPN 없이 기기 인벤토리 + 신뢰 추론 + 접근 프록시
- **NIST 800-207** — PE(판단) · PA(세션 발급) · PEP(시행) + 정책 입력(ID · 기기 · 위협 인텔 · SIEM)
- **CISA ZTMM** — 5개 축(ID · 기기 · 네트워크 · 앱 · 데이터) + 공통(가시성 · 자동화 · 거버넌스)
- **DoD** — 7개 축 · 152개 활동 · 91개 목표 레벨(FY2027)

### 바뀐 것 세 가지

```
주체:      사람 · 기기  →  워크로드  →  AI 에이전트
판단 주기:  접속 시 1회  →  세션 내내 지속
PEP 위치:  네트워크 경계  →  앱 앞  →  도구 호출 앞
```

## 2026 핵심 흐름: AI 에이전트

> "제로트러스트가 사람과 앱을 지키는 프레임워크에서 AI 기반 기업을 지키는 플랫폼으로 바뀌고 있다" — GuidePoint, 2026 상반기

### 왜 기존 모델로 부족한가

- 에이전트는 **정상 사용자와 같은 OAuth 토큰**을 씀 → 사용자 · 기기 · 자원 검증을 모두 통과 (SANS)
- 기존 ZT는 "느린 사람 + 예측 가능한 기계" 두 행위자만 가정. 에이전트는 **기계 속도 + 비결정적**인 제3의 유형 (Dark Reading)
- 질문이 바뀜: **"너는 누구냐" → "무엇을 하려는 거냐"** (신원 검증 → 의도 검증)

### 권고 통제 (Gartner 2026.11)

- 에이전트별 고유 ID
- 최소 권한 · 최소 행동 범위(agency)
- 결정론적 정책
- 마이크로세그멘테이션
- 도구 최소화로 행동 범위 제한
- 지속 모니터링

### 기술 요소

| 요소 | 기술 |
| --- | --- |
| 에이전트 ID | SPIFFE / SPIRE |
| 위임 | OAuth 2.0 Token Exchange (RFC 8693), On-Behalf-Of |
| 권한 | 사용자 권한 ∩ 에이전트 권한 (교집합) |
| 호출 인증 | 사용자→LLM, LLM↔LLM, LLM→도구 **매 호출** 짧은 수명 자격증명 |
| 고위험 행위 | 사람 확인 (CIBA 등 비동기 승인) |

## 학술 연구 주제

| 주제 | 내용 |
| --- | --- |
| **멀티 LLM 제로트러스트** | 모델 수준(강한 ID · 맥락 기반 접근제어) / 시스템 수준(사전 유지보수 · 블록체인 관리)으로 분류 |
| **ZTFM** (제로트러스트 파운데이션 모델) | IoT용. 과제: 확장성 · 안전한 오케스트레이션 · 해석 가능한 위협 원인 분석 · 동적 신뢰 보정 |
| **생성형 AI의 ZT 침식** | 생성형 AI가 현재 ZT 구축의 구조적 약점 3가지를 무기화 (MDPI JCP 2025) |
| **ML 지속 신뢰 평가** | 행동 학습 → 실시간 이상 탐지 → 동적 접근 조정 |
| **원격 증명** | Keylime 기반 5G VNF · 컨테이너별 IMA 증명 |

## 시장 · 성숙도

- Gartner: 2026년까지 성숙하고 측정 가능한 ZT 프로그램을 갖춘 대기업은 **10%**
- DoD: 2025년 초 기준 목표 레벨 활동 완료율 **14%**
- 시장 규모: 2026년 약 318억~484억 달러 (기관마다 편차 큼)
- **도입 의지와 실제 적용 사이의 격차**가 공통 과제
