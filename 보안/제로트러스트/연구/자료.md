> 제로트러스트 참고 자료 가이드
> 조사일: 2026-11-22
> 요약: **개념은 NIST, 국내 용어는 KISA, 실제 구성은 NIST 1800-35로 잡는다.** 벤더 자료는 구현 예시로만 본다.
> 관련: [[연구 동향]] · [[보안/제로트러스트/연구/오픈소스 프로젝트]]

## 읽는 순서

```
NIST SP 800-207  →  KISA 가이드라인 2.0  →  NIST SP 1800-35
   (개념·구조)         (국내 용어·성숙도)        (실제 구현 조합)
        ↓
  환경별 문서 (N2SF · 금융 · OT · 에이전틱 AI)
```

| 단계 | 목적 | 문서 |
| --- | --- | --- |
| 1. 원칙 | 공통 언어 잡기 | NIST 800-207, KISA 가이드라인 2.0 |
| 2. 진단 | 현재 수준 파악 | CISA ZTMM 2.0, KISA 성숙도 모델 해설서, 금융보안원 21개 진단 항목 |
| 3. 설계 | 환경별 적용 | N2SF 정보서비스 모델 11종, OT 안내서, 에이전틱 AI 안내서 |
| 4. 실증 | 남의 구축 사례 | NIST 1800-35, KISA N2SF 실증 사례집 |
| 5. 평가 | 공공 대응 | 국정원 사이버보안 실태평가 N2SF 항목 |

## NIST

모든 국내외 문서의 뿌리. **PE(정책 엔진) · PA(정책 관리자) · PEP(정책 시행점)** 구조가 여기서 나옵니다.

| 문서 | 핵심 | 링크 |
| --- | --- | --- |
| **SP 800-207** (2020) | 개념 · 논리 아키텍처. 가장 먼저 읽을 것 | [csrc.nist.gov](https://csrc.nist.gov/pubs/sp/800/207/final) |
| **SP 1800-35** (2025.06) | 24개 협력사 · 19개 구현 사례. EIG, 마이크로세그멘테이션, SDP, SASE | [최종본](https://csrc.nist.gov/pubs/sp/1800/35/final) · [웹 버전](https://pages.nist.gov/zero-trust-architecture/) |
| **SP 800-60** | 정보 분류 기준. 국정원 N2SF 데이터 분류의 참고 모델 | csrc.nist.gov |

국내 민간 기준 문서. 전부 [KISA 지식플랫폼 → 법령·가이드라인](https://www.kisa.or.kr/2060204)에 있습니다.

| 시기 | 문서 | 성격 |
| --- | --- | --- |
| 2023.07 | 제로트러스트 가이드라인 1.0 | 개념 · 원칙 · 참조모델 |
| 2024.12 | **제로트러스트 가이드라인 2.0** | 성숙도 모델 · 도입 절차 구체화. **국내 기준점** |
| 2025.12 | 제로트러스트 성숙도 모델 해설서 | 진단 방법 |
| 2025.12 | OT 환경의 제로트러스트 적용 안내서 | 산업제어 환경 |
| 2026.04 | N2SF 실증 사례집 | 공공기관 실증 결과 |
| 2026.11 | **에이전틱 AI 제로트러스트 안내서** | AI 에이전트 환경 |

## 주의

- **벤더 자료**(Zscaler, Palo Alto 등)는 자사 제품 구조로 제로트러스트를 정의함 → 개념은 NIST · CISA로, 벤더는 구현 예시로만
- **시장 규모 통계**는 기관마다 편차 큼 (2026년 기준 약 318억~484억 달러) → 인용 시 출처 명시
- **Gartner · Forrester 본문은 유료.** 무료 요약이나 벤더가 재배포한 사본으로 대체

## 점검 목록

- [ ] NIST 800-207의 PE · PA · PEP를 설명할 수 있는가
- [ ] KISA 2.0 성숙도 단계를 알고 있는가
- [ ] 내 환경이 민간 / 공공(N2SF) / 금융 중 어디인지 정했는가
- [ ] 해당 트랙의 진단 항목으로 현재 수준을 매겨봤는가
- [ ] NIST 1800-35에서 내 환경과 비슷한 구현 사례를 찾았는가
- [ ] AI 에이전트를 쓴다면 에이전틱 AI 안내서를 읽었는가

## 용어

| 용어 | 뜻 |
| --- | --- |
| **PE / PA / PEP** | 정책 엔진(판단) · 정책 관리자(세션 발급) · 정책 시행점(차단·허용) |
| **ZTNA** | 제로트러스트 네트워크 접근. VPN 대체 |
| **SASE / SSE** | 네트워크+보안 클라우드 통합 / 그중 보안 부분 |
| **EIG** | 강화된 ID 거버넌스. NIST 1800-35의 주요 접근법 |
| **N2SF** | 국가 망 보안체계. 망분리 대신 C·S·O 등급별 통제 |
| **CDS** | 크로스 도메인 솔루션. 망 간 안전한 통신 |
| **NHI** | 비인간 신원 (서비스 계정, 워크로드, AI 에이전트) |
