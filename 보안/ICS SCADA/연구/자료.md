## 읽는 순서

```
Purdue 모델 · 용어   →  NIST SP 800-82r3  →  IEC 62443 (3-2 · 3-3)
  (구조 · 계층)          (OT 보안 통제)         (구역 · 도관 · 보안 수준)
        ↓
MITRE ATT&CK for ICS  →  국내 문서 (국정원 · KISA · 산업부)  →  사고 사례
  (공격 기법)                (규제 · 점검 대응)                  (Stuxnet · Industroyer 등)
```

| 단계 | 목적 | 문서 |
| --- | --- | --- |
| 1. 구조 | IT와 OT 차이 · 계층 이해 | Purdue 모델(ISA-95), NIST 800-82r3 2~3장 |
| 2. 통제 | 무엇을 지켜야 하나 | NIST 800-82r3, IEC 62443-3-3 |
| 3. 설계 | 망 분리 · 구역 설계 | IEC 62443-3-2 (Zone · Conduit), CISA 심층 방어 권고 |
| 4. 위협 | 공격자 관점 | MITRE ATT&CK for ICS, Dragos · Claroty 연간 보고서 |
| 5. 국내 | 점검 · 규제 대응 | 국정원 제어시스템 보안 가이드라인, KISA 스마트공장 가이드, 정보통신기반 보호법 |

## 핵심 개념 정리

### IT vs OT 우선순위

```
IT:  기밀성(C)  >  무결성(I)  >  가용성(A)
OT:  가용성(A)  >  무결성(I)  >  기밀성(C)   + 안전(Safety)이 최우선
```

- 패치 · 재부팅이 어렵다 (수년~수십 년 운영)
- 프로토콜 대부분이 **인증 · 암호화 없음** (Modbus, DNP3, S7comm, BACnet)
- 능동 스캔이 장비를 멈출 수 있다 → **수동 모니터링 우선**

### Purdue 모델

| 레벨 | 구성 | 예 |
| --- | --- | --- |
| 5 · 4 | 기업 IT | ERP, 메일 |
| 3.5 | **IT/OT DMZ** | 히스토리안 복제, 패치 서버, 원격 접속 점프 서버 |
| 3 | 운영 관리 | MES, 히스토리안, 엔지니어링 워크스테이션 |
| 2 | 감시 제어 | SCADA 서버, HMI |
| 1 | 기본 제어 | PLC, RTU, IED |
| 0 | 물리 프로세스 | 센서, 액추에이터, 밸브 |

| 프로토콜 (포트) | 분야 | 보안 확장 |
| --- | --- | --- |
| Modbus TCP (502) | 범용 | Modbus/TCP Security (TLS, 포트 802) |
| DNP3 (20000) | 전력 · 수도 | DNP3 Secure Authentication |

## 점검 목록

- [ ] IT/OT 사이에 DMZ(레벨 3.5)가 있고 직접 통신이 막혀 있는가
- [ ] 원격 접속이 점프 서버 + MFA로만 가능한가
- [ ] OT 자산 목록(PLC 펌웨어 버전 포함)이 있는가
- [ ] 수동(패시브) 네트워크 모니터링이 있는가
- [ ] SIS가 제어망과 분리되어 있는가
- [ ] PLC 로직 · 설정 백업과 무결성 확인 절차가 있는가
- [ ] USB · 이동식 매체 통제가 되는가
