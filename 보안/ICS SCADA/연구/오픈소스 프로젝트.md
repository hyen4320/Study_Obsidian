> ICS · SCADA 오픈소스 프로젝트 · 용도별 정리
> 조사일: 2026-11-25
> 요약: **방어는 패시브 모니터링(Zeek + ICSNPP · Malcolm), 학습은 OpenPLC + 시뮬레이터 테스트베드로 시작한다.** 실제 운영망에 공격 · 스캔 도구를 돌리지 않는다.
> 관련: [[보안/ICS SCADA/연구/자료]] · [[보안/ICS SCADA/연구/연구동향]] · [[보안/제로트러스트/연구/오픈소스 프로젝트]]

## 용도 지도

```
[테스트베드]  OpenPLC · FUXA · GRFICS · Labshock
      ↓ 트래픽
[프로토콜]    pymodbus · open62541 · libiec61850 · opendnp3
      ↓ 미러링(SPAN/TAP)
[모니터링]    Zeek + ICSNPP · Suricata · Malcolm
      ↓
[분석·평가]   CSET · ATT&CK for ICS · HAI 데이터셋
```

---

## 1. PLC · SCADA · HMI (테스트베드 구성용)

| 프로젝트 | 성격 | 비고 |
| --- | --- | --- |
| **OpenPLC** | IEC 61131-3 소프트 PLC. 라즈베리파이 · 리눅스 · 윈도우 | 학습용 PLC 사실상 표준. Modbus · DNP3 · EtherNet/IP |
| **FUXA** | 웹 기반 SCADA/HMI 에디터 | Modbus · OPC UA · S7 · MQTT |
| **Rapid SCADA** | .NET 기반 SCADA 플랫폼 | 현장 실사용 사례 있음 |
| **ScadaBR** | Java 웹 SCADA | 오래됐지만 연구 테스트베드에 자주 등장 |
| **Node-RED** | 플로우 기반 IIoT 연동 | 게이트웨이 · 데이터 수집 |
| **Eclipse 4diac** | IEC 61499 분산 제어 | 차세대 PLC 연구 |

## 2. 프로토콜 라이브러리

| 프로토콜 | 프로젝트 | 언어 |
| --- | --- | --- |
| Modbus | **pymodbus** · libmodbus | Python · C |
| OPC UA | **open62541** · asyncua · Eclipse Milo | C · Python · Java |
| IEC 61850 · 60870-5-104 | **libiec61850** · lib60870 (MZ Automation) | C |
| DNP3 | opendnp3 (Step Function I/O) | C++ |
| S7comm | python-snap7 | Python |
| 범용 패킷 조작 | Scapy (Modbus · DNP3 contrib 레이어) | Python |

## 3. 네트워크 모니터링 · 탐지 (방어 핵심)

| 프로젝트 | 성격 | 비고 |
| --- | --- | --- |
| **Zeek + ICSNPP** | CISA · INL이 만든 Zeek용 ICS 프로토콜 파서 모음 | BACnet · DNP3 · EtherNet/IP · S7comm · Modbus 상세 로그 |
| **Malcolm** | CISA 패킷 분석 통합 스택 (Zeek · Suricata · Arkime · OpenSearch) | PCAP 넣으면 대시보드까지. OT 분석 입문에 최적 |
| **Suricata** | IDS/IPS. Modbus · DNP3 · ENIP 파서 내장 | ICS 룰셋 추가 활용 |
| **Wireshark** | 거의 모든 ICS 프로토콜 디섹터 | 분석 기본기 |
| **GRASSMARLIN** | NSA 패시브 ICS 네트워크 매핑 | 보관(archived). 참고용 |
| **Wazuh** | SIEM/XDR | HMI · 엔지니어링 워크스테이션(윈도우) 감시 |

## 4. 자산 식별 · 평가

| 프로젝트 | 성격 | 주의 |
| --- | --- | --- |
| **CSET** | CISA 자가 평가 도구. IEC 62443 · NIST 800-82 기반 질문지 | 오프라인 설치 가능 |
| Nmap NSE (`modbus-discover`, `s7-info`, `enip-info`, `bacnet-info`) | 능동 식별 | **운영망 금지**. 테스트베드에서만 |
| plcscan · redpoint | PLC 식별 스크립트 | 동일 |

## 5. 허니팟 · 기만

| 프로젝트 | 성격 |
| --- | --- |
| **Conpot** | ICS 허니팟 (Modbus · S7 · BACnet 등). T-Pot에 포함 |
| GridPot | 전력망 시뮬레이션 허니팟 (GridLAB-D 연동) |
| T-Pot | 다중 허니팟 플랫폼 |

## 6. 테스트베드 · 시뮬레이터 · 데이터셋

| 프로젝트 | 성격 |
| --- | --- |
| **GRFICS v2** | 화학 공정 3D 시뮬레이션 + OpenPLC + HMI 가상 환경. 공격 · 방어 실습 |
| **Labshock** | Docker 기반 OT 보안 랩 (PLC · SCADA · IDS 포함) |
| MiniCPS | Mininet 기반 CPS 네트워크 시뮬레이터 (SWaT 모사) |
| ICSSIM | Docker 기반 ICS 테스트베드 프레임워크 |
| **HAI 데이터셋** | 국가보안기술연구소. 이상 탐지 학습용 (보일러 · 터빈 · 수처리 HIL) |
| SWaT · WADI | 싱가포르 iTrust 수처리 데이터셋 (신청제) |
| MITRE Caldera for OT | ATT&CK for ICS 기반 공격 에뮬레이션 플러그인 |

## 7. 공격 연구 (테스트베드 전용)

| 프로젝트 | 성격 |
| --- | --- |
| ISF (Industrial Exploitation Framework) | Metasploit 유사 ICS 익스플로잇 프레임워크 |
| Metasploit `auxiliary/scanner/scada/*` | Modbus · S7 등 보조 모듈 |
| ctmodbus | Modbus 대화형 클라이언트 |

> 공격 도구는 반드시 격리된 랩에서만. PLC는 비정상 패킷 하나로 멈출 수 있다.

## 점검 목록

- [ ] 능동 스캔 도구를 운영망이 아닌 랩에서만 쓰는가
- [ ] 모니터링이 SPAN/TAP 기반 패시브인가
- [ ] 프로젝트가 유지보수 중인가 (GRASSMARLIN · ScadaBR 등 보관 · 정체 확인)
- [ ] 라이선스 확인 (OpenPLC는 GPL 계열 — 제품 내장 시 주의)
- [ ] 탐지 결과를 ATT&CK for ICS 기법 ID로 매핑했는가
