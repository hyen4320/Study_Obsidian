> DaaS 연구 동향 · 초기부터 2026년까지

> 출처 기준: 정부기관(NIST · CISA · KISA · 국정원), 컨퍼런스(Black Hat), 대기업 · 분석기관(Microsoft · AWS · Gartner · Omnissa · Citrix)만 사용
> 요약: **DaaS의 사용자가 사람에서 AI 에이전트로 넓어지고 있다.** 2026년 Microsoft · AWS 모두 "에이전트용 클라우드 PC"를 정식 출시했다. 보안 쪽 최대 위험은 여전히 인터넷에 노출된 게이트웨이다.

## 발전 단계

| 시기 | 단계 | 핵심 | 대표 |
| --- | --- | --- | --- |
| 1990s~2000s | 터미널 서버 | 서버 1대를 여러 사용자가 공유 | Citrix MetaFrame, Windows Terminal Services |
| 2006~2015 | 온프레미스 VDI | 사용자별 VM, 하이퍼바이저 위 데스크톱 | VMware View/Horizon, Citrix XenDesktop. NIST 800-125(2011) |
| 2014~2019 | 1세대 DaaS | 클라우드 사업자가 VDI 운영 | Amazon WorkSpaces(2014), Azure Virtual Desktop(2019) |
| 2020~2022 | 원격근무 폭증 | 코로나로 원격 접속 수요 급증, RDP · VPN 공격 증가 | NIST ITL Bulletin 2020.03, Windows 365(2021) |
| 2023~2025 | 게이트웨이 공격 · 업계 재편 | Citrix Bleed 계열 대규모 악용, VMware EUC 분사 | CVE-2023-4966, CVE-2025-5777, Omnissa 출범(2024.07) |
| 2026~ | **에이전트용 DaaS · 주권 클라우드** | AI 에이전트가 클라우드 PC에서 실제 화면을 조작 | Windows 365 for Agents, WorkSpaces for AI agents |

### 바뀐 것 세 가지

```
사용자:    사람  →  사람 + AI 에이전트 (computer use)
위치:      자체 데이터센터  →  퍼블릭 클라우드  →  주권 · 규제 대응 클라우드
접근 통제: VPN + 비밀번호  →  게이트웨이 + MFA  →  조건부 접근 + 세션 재평가 + 에이전트 ID
```

## 1. 2026 핵심 흐름: AI 에이전트용 클라우드 PC

### 왜 DaaS인가

에이전트가 API 없는 레거시 앱을 쓰려면 **실제 화면을 보고 클릭**해야 한다(computer use). 사용자의 실물 PC에서 돌리면 위험하므로, **격리된 일회성 클라우드 PC**에서 실행하고 감독 · 기록하는 구조가 필요해졌다.

### Microsoft — Windows 365 for Agents

| 시점 | 내용 |
| --- | --- |
| 2026 상반기 | 공개 미리보기 → Build 2026에서 개발자 · 에이전트용 기능 발표 |
| 2026.06 | **정식 출시(GA)**, 에이전트에도 **조건부 접근** 적용 GA |
| 2026.11 Ignite | Copilot Credits로 과금 · 거버넌스 통합, Copilot Studio의 computer-use 도구로 제공, 에이전트 ID로 온프레미스 레거시 앱 접근(미리보기), 상시 실행 에이전트용 지속형 Cloud PC(Frontier 미리보기) |
| 예정 | Microsoft Foundry에서 MCP 서버를 붙여 Cloud PC로 computer-use 작업 실행(미리보기, 2027 초) |

같은 Ignite 2026의 사람용 기능:
- 상황 기반 리디렉션 GA, **화면 출력 보호 GA · 입력 보호 미리보기**
- Windows App용 모바일 앱 관리(MAM) 미리보기
- **Windows 365 Reserve**: 단말 장애 시 임시 Cloud PC 제공 (업무 연속성)
- Intune 안의 AI 관리 도우미(미리보기), GPU Cloud PC 개선(NVIDIA, 미리보기 예정)

### AWS — Amazon WorkSpaces for AI agents

| 시점 | 내용 |
| --- | --- |
| 2026.06 | **정식 출시**. MCP 도구 전달, **세션 중 실시간 접근 취소**, 도메인 가입 플릿 |
| 2026.10 | 관리형 MCP 서비스가 인증 · 데스크톱 연결 처리(OAuth), 앱 카탈로그 MCP 도구 |
| 2026.11 | Linux · Windows 11 데스크톱 지원(이전엔 Windows Server만). **OIDC 로그인 + 사용자 대리(on-behalf-of) 로그인** → 에이전트가 로그인한 사용자 권한으로만 동작. **세션 재생**: 화면을 영상 + 에이전트 행동 설명 텍스트로 기록, 고객 S3 · 고객 키로 암호화 저장 |

같은 해 사람용 기능: 개발자용 **중첩 가상화**(Docker · WSL2 · Android 에뮬레이터, 2026.08 → 11월 셀프서비스), 새 Windows 클라이언트 + 문제 진단 도구 WorkSpaces Advisor(2026.11)

### 보안 관점에서 본 에이전트용 DaaS

| 위험 | 두 사업자의 대응 |
| --- | --- |
| 에이전트가 과한 권한을 가짐 | 사용자 대리 로그인(AWS), 에이전트 ID + 조건부 접근(Microsoft) |
| 에이전트가 무엇을 했는지 모름 | 세션 재생 + 행동 기록(AWS), Copilot 거버넌스 통합(Microsoft) |
| 잘못된 동작이 계속됨 | 세션 중 실시간 접근 취소(AWS) |
| 사용자 PC 오염 | 격리된 별도 클라우드 PC에서 실행 |

> 제로트러스트 노트의 "PEP가 도구 호출 앞으로 이동" 흐름과 같다. DaaS에서는 **클라우드 PC 세션 자체가 에이전트의 실행 경계(샌드박스) + 감사 지점**이 된다. → [[보안/제로트러스트/연구/연구 동향]]

## 2. 시장 동향 (Gartner Magic Quadrant for DaaS)

| 판 | 핵심 |
| --- | --- |
| 2025 (2025.08) | 주 용도는 여전히 **안전한 원격근무**. 비용 최적화 · 운영 · 지속가능성 목적 배포 증가 |
| 2026 (2026.08) | DaaS는 널리 배포됐지만 **보통 일부 직원에게만**, VDI 대체가 많음. **고보안 · 규제 준수 · 주권** 중심 배포 증가, **AI 에이전트를 포함한 AI 작업 실행 환경**으로 쓰이기 시작 |

- 2026 MQ 대상: AWS, Citrix, Microsoft, Omnissa, Parallels 등. AWS · Omnissa · Parallels가 리더 발표

### 업계 재편

- **Omnissa**: Broadcom이 VMware를 인수한 뒤 EUC 사업부(Horizon · Workspace ONE)를 KKR에 매각 → 2024.07.01 독립 회사로 출범
- **Citrix**: Cloud Software Group 소속. 게이트웨이(NetScaler) 취약점이 연이어 KEV에 등재

## 3. 위협 동향: 게이트웨이가 계속 뚫린다

| 시기 | 사건 | 의미 |
| --- | --- | --- |
| 2019 | Black Hat USA "Poisoned RDP" | 악성 서버가 RDP 클라이언트를 공격. **접속하는 쪽도 안전하지 않다** |
| 2023 | Black Hat USA "I Watched You Roll the Die" | RDP가 랜섬웨어 주요 침투 경로임을 허니넷으로 확인 |
| 2023.10~ | **Citrix Bleed (CVE-2023-4966)** | 게이트웨이 메모리에서 세션 토큰 유출 → MFA 우회. CISA 전용 지침 |
| 2025.07 | **CVE-2025-5777** | 같은 계열 메모리 과다 읽기. KEV 등재 다음 날 조치 기한. 패치 후 세션 강제 종료 필요 |
| 2026.09~10 | **NetScaler 제로데이 (CVE-2026-88771 · 88772 · 88779 · 107406)** | 원격 코드 실행, 전 세계 악용. 재부팅 유도로 주입 코드 실행 연계. CISA가 **패치 전 침해 확인 · 증거 보존** 권고 |

```
흐름:  RDP 직접 노출 공격  →  게이트웨이 세션 토큰 탈취  →  게이트웨이 원격 코드 실행
교훈:  DaaS로 데스크톱을 숨겨도, 게이트웨이가 새 경계가 된다
       → 패치 + 세션 무효화 + 비밀 교체 + 로그 외부 보관까지 한 세트
```

## 4. 국내 동향

### 공공 DaaS 확산

- 망분리 환경의 **인터넷 PC를 DaaS로 대체**하는 사업이 대표 유형
- **우정사업본부 클라우드 기반 인터넷 PC(DaaS)** (2026): CSAP DaaS 인증 보유 사업자로 입찰 제한, 네이버클라우드 수주 발표. KT클라우드 · NHN클라우드와 경쟁
- 행정안전부: 2030년까지 공공 정보시스템 클라우드 전면 전환 추진(2026.03 발표). 공공 DaaS의 정의 · 보안 · 조달 기준 정비 요구가 국회 토론회 등에서 제기 중
- 2026년 행안부 차원의 공공 DaaS 전용 로드맵은 조사 시점에 확인되지 않음

### 인증 · 보안체계 개편

| 흐름 | 내용 |
| --- | --- |
| CSAP 등급제 | 2024 상 · 중 · 하 전면 시행. 기존 DaaS 인증은 중등급 인정 방향 |
| **공공 클라우드 검증 일원화** (2026 논의) | 과기정통부 CSAP → **국정원 중심 단일 검증 체계**로 개편 추진. 민관 검증심의위원회 운영, 새 제도 시행 전까지 기존 CSAP 유지 · 기존 인증 유효기간(5년) 인정. 공공 클라우드 등급을 N2SF 기준 C · S · O로 개편 방향 (사이버 서밋 코리아 2026 발표) |
| **N2SF** | 국가 사이버보안 기본지침 전면 개편, 2026.05 시행 보도. 원격근무 목적 업무망 DaaS 활용 허용 입장 보도(2026.06) — 국정원 원문 확인 필요 |
| N2SF 도입 지원 | KISA 2026 도입 지원사업 6개 연합체 선정 |

> 국내 핵심 질문이 "DaaS를 써도 되나"에서 **"어떤 등급(C · S · O)의 업무에, 어떤 검증을 받은 DaaS를 쓰나"**로 바뀌고 있다.

## 2026 핵심 정리

| 흐름 | 근거 | 보안 시사점 |
| --- | --- | --- |
| 에이전트용 클라우드 PC | Windows 365 for Agents GA(2026.06), WorkSpaces for AI agents GA(2026.06) | 에이전트 ID · 대리 권한 · 세션 기록 · 실시간 차단 |
| 화면 · 입력 보호 강화 | Windows 365 출력 보호 GA · 입력 보호 미리보기 | 화면 캡처 · 키로깅 대응 |
| 업무 연속성용 DaaS | Windows 365 Reserve | 단말 장애 · 랜섬웨어 시 임시 업무 환경 |
| 주권 · 규제 중심 배포 | Gartner MQ 2026 | 데이터 위치 · 운영 주체 확인 |
| 게이트웨이 제로데이 지속 | CISA KEV (Citrix 2023 · 2025 · 2026) | 패치 + 세션 무효화 + 비밀 교체 |
| 국내 검증 체계 개편 | CSAP → 국정원 단일 검증 논의, N2SF | C · S · O 등급별 DaaS 적용 범위 확인 |

## 점검 목록

- [ ] 에이전트를 DaaS에서 돌린다면 사람 계정과 분리된 에이전트 ID를 쓰는가
- [ ] 에이전트 세션이 기록되고, 이상 행동 시 즉시 끊을 수 있는가
- [ ] 게이트웨이 KEV 등재 시 "패치 → 세션 종료 → 비밀 교체" 절차가 있는가
- [ ] 화면 출력 보호 · 워터마크 등 단말 측 유출 대책이 있는가
- [ ] 공공 사업이라면 검증 체계 개편 일정(기존 CSAP 유효기간)을 반영했는가
