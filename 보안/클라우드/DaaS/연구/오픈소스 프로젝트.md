> DaaS · VDI 오픈소스 프로젝트 · 구성요소별 정리
> 조사일: 2026-11-25 (라이선스 · 활동 여부는 GitHub API로 확인)
> 요약: **상용 DaaS 하나를 통째로 대체하는 오픈소스는 없다.** 하이퍼바이저 + 브로커 + 게이트웨이 + 디스플레이 프로토콜을 골라 조합한다. 학습용 최소 구성은 **Proxmox VE + xrdp + Apache Guacamole**.
> 관련: [[보안/클라우드/DaaS/연구/개념]] · [[보안/클라우드/DaaS/연구/자료]] · [[보안/클라우드/DaaS/연구/연구동향]] · [[보안/제로트러스트/연구/오픈소스 프로젝트]]

## 구성요소 지도

```
사용자 브라우저 · 클라이언트
        │
[게이트웨이 · 웹 접속]   Apache Guacamole · Selkies · KasmVNC
        │   ← 앞단에 Keycloak(SSO · MFA) · Pomerium(PEP) 붙이기
[브로커]                OpenUDS
        │
[디스플레이 프로토콜]    xrdp(RDP) · FreeRDP · SPICE · VNC
        │
[하이퍼바이저 · 관리]    Proxmox VE · oVirt · OpenStack · KVM/libvirt
```

## 1. 게이트웨이 · 웹 접속

| 프로젝트 | 성격 | 라이선스 | 비고 |
| --- | --- | --- | --- |
| **Apache Guacamole** | 클라이언트 없는(브라우저) 원격 데스크톱 게이트웨이. RDP · VNC · SSH | Apache-2.0 | 사실상 표준. 단, **이미 있는 머신에 연결**하는 구조라 VM을 자동으로 만들어 주지 않음 |
| **Selkies** | 저지연 GPU 가속 웹 원격 데스크톱 스트리밍. 컨테이너 · Kubernetes · HPC용 | MPL-2.0 | LinuxServer.io가 2025.06 모든 데스크톱 이미지를 Selkies로 전환 |
| **KasmVNC** | 웹 기반 최신 VNC 서버 · 클라이언트 | GPL-2.0 | Kasm Workspaces(상용 플랫폼, 무료 CE 있음)의 오픈소스 핵심 부품 |

## 2. 브로커

| 프로젝트 | 성격 | 라이선스 | 비고 |
| --- | --- | --- | --- |
| **OpenUDS** | 멀티 플랫폼 연결 브로커 (Virtual Cable + 스페인 대학들) | BSD-3-Clause | Proxmox · oVirt · OpenStack 등과 연동해 **풀 생성 · 할당**까지. 오픈소스 VDI에서 브로커 역할을 하는 몇 안 되는 프로젝트 |

> OpenStack에는 공식 VDI 프로젝트가 없다. OpenStack 메일링 리스트에서도 "VDI/DaaS를 어떻게 하나"가 반복 질문이고, 보통 Guacamole · OpenUDS를 붙인다.

## 3. 디스플레이 프로토콜 · 서버

| 프로젝트 | 성격 | 라이선스 |
| --- | --- | --- |
| **xrdp** | 리눅스용 오픈소스 RDP 서버 | Apache-2.0 |
| **FreeRDP** | RDP 라이브러리 · 클라이언트 (Guacamole도 내부 사용) | Apache-2.0 |
| **SPICE** | KVM/QEMU 가상 머신용 원격 디스플레이 프로토콜 (Proxmox · oVirt 기본) | LGPL 계열 |
| **Sunshine** (+ Moonlight 클라이언트) | 자체 호스팅 고성능 스트리밍 호스트. GPU 작업 · 그래픽 데스크톱 | GPL-3.0 |
| **RustDesk** | 자체 호스팅 원격 제어 (TeamViewer 대체) | AGPL-3.0 |

> RustDesk · Sunshine은 VDI라기보다 "원격 제어 · 스트리밍"이다.

## 4. 하이퍼바이저 · 관리 평면

| 프로젝트 | 성격 | 라이선스 | 비고 |
| --- | --- | --- | --- |
| **Proxmox VE** | KVM + LXC 가상화 관리 플랫폼 | AGPL-3.0 | 학습 · 소규모 VDI에 가장 쉬움. SPICE 내장 |
| **oVirt** | KVM 가상화 관리 (Red Hat 계열 커뮤니티) | GitHub 표기 없음(확인 필요) | 활동 중. VDI 기능(풀 · SPICE) 내장 |
| **OpenStack** | 대규모 IaaS | Apache-2.0 | 사업자 규모. DaaS 사업자의 IaaS 기반으로 쓰임 |
| KVM / libvirt | 리눅스 하이퍼바이저 · 관리 API | GPL / LGPL | 모든 위 프로젝트의 바닥 |

## 학습용 참조 스택

| 역할 | 선택 |
| --- | --- |
| 하이퍼바이저 | Proxmox VE |
| 데스크톱 | 리눅스 VM + xrdp, 또는 Windows VM(RDP) |
| 브로커 (선택) | OpenUDS — 풀 자동 생성 · 할당을 실습하려면 |
| 웹 게이트웨이 | Apache Guacamole |
| 인증 | Keycloak (OIDC · MFA) → Guacamole 연동 |
| 감시 | Wazuh 에이전트를 골든 이미지에 포함 |
| 공격 · 방어 실습 | PyRDP로 RDP 중간자 위험 확인 (격리된 랩) |

### 실습 순서 (보안 관점)

1. Guacamole만으로 VM 1대 연결 → **클립보드 · 파일 전송 · 드라이브 리디렉션 끄고 켜며** 차이 확인
2. Keycloak 붙여 MFA 강제 → 게이트웨이가 PEP가 되는 구조 확인
3. 골든 이미지 해시 기록 → 일부러 변경 후 탐지되는지 확인
4. 게이트웨이 로그를 Wazuh로 보내 비정상 로그인 탐지

## 점검 목록

- [ ] 라이선스 확인 (AGPL: Proxmox · RustDesk — 서비스로 제공 시 소스 공개 의무 검토)
- [ ] 게이트웨이(Guacamole 등)를 인터넷에 바로 노출하지 않고 SSO · MFA 뒤에 두었는가
- [ ] 리디렉션 기능(클립보드 · 파일 · 프린터)을 기본 차단했는가
